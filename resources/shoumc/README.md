# SHOUMC 素材来源

配色取自 [SHOUMC 官网](https://shoumc.com) 于 2026-10-11 使用的 [样式表](https://shoumc.com/assets/css/styles.aa9e6caf.css)：米白 `--cc-bg: #fdf9f3`、深棕 `--cc-bg-deep: #5d453e`、浅色卡片 `--cc-panel: #f9efe4`、酒红 `--ifm-color-primary: #904855`，标题使用其深色 `--ifm-color-primary-dark: #74313e`。

左上角使用用户指定的 Wiki 第一张原版潮涌核心方块图，别名 `Conduit.png`、归档文件名 `Conduit_JE1_BE1.png`。下载自 [Wiki 归档的 Conduit 页面](https://wiki.ronlab.site/content/minecraftwiki_en_all_maxi_2025-11/Conduit) 的第一张图片链接；该文件是未激活的小方块，不是第二张激活动画。归档虽然使用 `.png` URL，实际响应为 WebP，本仓库仅无损转存为 PNG，未重绘、换色或修改解码像素。渲染时裁掉透明边缘，按比例以最近邻缩到可见主体 49×52 px，不增加发光效果或装饰。

素材属于 Minecraft/Mojang 原游戏资产，不作为本项目原创资产。下载地址、响应格式、SHA-256 和官网色值保存在 [source.json](source.json)。SHOUMC 英文标题复用 [WZBC 原版 Java 位图字体及来源说明](../wzbcmc/README.md)。每台服务器卡片的图标另取实时查询返回值，不使用此品牌图替代服务器 icon。
